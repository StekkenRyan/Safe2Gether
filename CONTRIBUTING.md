# Beitragen zu Safe2Gether

Safe2Gether ist ein Open-Source-Projekt unter AGPL v3. Contributions sind willkommen —
egal ob Bugfix, Feature-Vorschlag oder Dokumentationsverbesserung.

---

## Bevor du anfängst: Issue öffnen

Bitte öffne vor größeren Änderungen zuerst ein Issue und beschreibe, was du vorhast.
So vermeiden wir doppelte Arbeit und können die Richtung frühzeitig abstimmen.

Für kleine Fixes (Tippfehler, Dokumentation) kannst du direkt einen PR einreichen.

---

## Branch-Strategie

| Branch | Zweck |
|--------|-------|
| `main` | Stabiler Stand — direkter Push nur durch Maintainer |
| `feature/<name>` | Neue Features |
| `fix/<name>` | Bugfixes |

PRs gehen immer gegen `main`.

---

## Pull Requests

Ein guter PR enthält:

- **Was** wurde geändert — kurze Zusammenfassung
- **Warum** — Bezug zum Issue oder Motivation
- **Wie testen** — Schritte zum Nachvollziehen der Änderung

Für neue Features werden Tests erwartet. Der Maintainer führt ein Code-Review durch,
bevor ein PR gemergt wird.

---

## CLA — Contributor License Agreement

Externe Contributions (von Personen außerhalb des Kern-Teams) benötigen ein
**Contributor License Agreement (CLA)**. Das CLA ermöglicht ein späteres Dual-Licensing
für einen Enterprise-Tier, ohne den Open-Source-Charakter zu verändern.

Der Maintainer schickt das CLA nach deinem ersten PR zu.

---

## Verhaltenskodex

Respektvoller, sachlicher Umgang ist Voraussetzung für eine Zusammenarbeit.
Diskriminierung, Belästigung oder persönliche Angriffe werden nicht toleriert.
