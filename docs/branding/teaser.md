# Teaser-Posts — Safe2Gether

## Markendirection

Kern-Shift: Sicherheit ist kein Solo-Thema. Safe2Gether setzt auf **gegenseitige Hilfe in der Community** —
Nearby Alerting, geteilte Verantwortung, kollektives Wohlbefinden. Das "2gether" ist wörtlich gemeint.

Ton: zugänglich, warm, gemeinschaftlich. Kein Alarm-Vokabular, kein Jargon.

---

## Teaser-Varianten

### Individuelle Sicherheit (Ausgangspunkt)

**A — Szenario**
```
Du bist allein unterwegs.
Kein Netz. Kein Signal.
Niemand weiß, wo du bist.

Das ändern wir.

Safe2Gether — coming soon.
```

**B — Invertierte Logik** *(stärkster Hook)*
```
Andere Apps handeln, wenn du auf einen Knopf drückst.

Wir handeln, wenn du es nicht mehr kannst.

Safe2Gether — coming soon.
```

**C — Alltagsnah**
```
„Ich meld mich, wenn ich da bin."

Was, wenn du das nicht mehr kannst?

Safe2Gether ist für genau diesen Moment.
Coming soon.
```
