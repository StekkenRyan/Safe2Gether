# Branding — Safe2Gether

## Tagline / Bio

> Für alle, die allein unterwegs sind.  
> Sicherheit, die im Notfall für dich spricht.

Ton: zugänglich, klar, nicht technisch. Kein Alarm-Vokabular, kein Jargon.

## Wordmark

**Aufbau:** `Safe` + `2` + `Gether` — drei separate Layer, die "2" farblich hervorgehoben.

**Font:** Avenir Next Medium (macOS vorinstalliert) — alternativ Inter SemiBold (rsms.me/inter)  
**Tracking:** +20–40 (leicht erhöhter Buchstabenabstand)

## Farben

| Rolle | Hex | Verwendung |
|-------|-----|-----------|
| Primary | `#1B3F5C` | Haupttext ("Safe", "Gether"), Hintergründe |
| Accent | `#27B0A0` | Die "2" im Wordmark, Highlights |
| Background | `#FFFFFF` | Standard-Canvas |
| Dark BG | `#0F2132` | Invertierte Variante |

## Icon / Symbol

Konzept: die Ziffer **"2" als Herzschlag-Linie** — die Kurve der Zwei geht nahtlos in eine EKG-Linie über.  
Farbe: Accent (`#27B0A0`) auf weißem Grund.  
Format: SVG (skalierbar) + 1024×1024 PNG (App Icon iOS/Android).
